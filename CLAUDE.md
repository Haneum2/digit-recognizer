# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Handwritten digit recognizer, developed as two separate versions:

- `desktop_version/`: Python + tkinter + PyTorch CNN (working). See `desktop_version/CLAUDE.md`.
- `web_version/`: browser version (not started yet). See `web_version/CLAUDE.md`.

Both show the recognized digit and its confidence.

## Conventions (apply to both versions)

- All code and comments are written in English.
- Every new file starts with a comment giving its creation date and time, e.g. `# Created: 2026-09-28 14:30`, using the file type's comment syntax (`rem` in .bat, `<!-- -->` in HTML/Markdown).
